  20260923 旺咪家行事曆 — 單筆行程 ICS 匯出 變更摘要
  日期：2026-09-23
================================================================================

【USER 需求】
  在當日行程列表與行程詳細畫面加入「加入手機行事曆」功能，將目前查看的單次
  行程匯出為標準 .ics。重複行程只匯出當次 occurrence，不輸出整個系列。

--------------------------------------------------------------------------------

【影響範圍】

  程式位置一：js/ics-export.js
  函式／區塊：buildIcsContent、buildShortcutPayload、buildShortcutUrl、
              addToDeviceCalendar
  說明：產生 iCalendar 內容、安全檔名與瀏覽器下載。
  異動：新增 VCALENDAR／VEVENT 必要欄位、floating local time、成員說明、
        ICS 特殊字元跳脫、跨日結束日期與單次 UID。iOS Safari 對 Blob 與 data URI
        都無法可靠開啟行事曆，前兩版只更換下載 URI 類型仍未跳脫平台限制；最終改用
        Shortcuts URL Scheme 呼叫原生「新增家庭行程」捷徑。其他平台維持 Blob 下載。

  修改前：
    無此功能。

  修改後：
    export function buildIcsContent(event, occurrenceDateKey)
    export function buildIcsFilename(event, occurrenceDateKey)
    export function buildShortcutPayload(event, occurrenceDateKey)
    export function buildShortcutUrl(event, occurrenceDateKey, shortcutName)
    export function addToDeviceCalendar(event, occurrenceDateKey)

  ─────────────────────────────────────────────────────────────────────────────

  程式位置二：js/app.js
  函式／區塊：openDayEventsModal、openEventDetail、withMemberNames
  說明：當日行程列表與詳細 Modal。
  異動：兩個畫面都加入「加入手機行事曆」按鈕，並把目前 occurrence 日期及成員
        姓名傳給 ICS 匯出模組。

  ─────────────────────────────────────────────────────────────────────────────

  程式位置三：css/style.css
  函式／區塊：event-actions、event-detail-body
  說明：行程操作按鈕的手機版配置。
  異動：操作列允許換行，避免新增第三個按鈕後在窄螢幕溢出。

  ─────────────────────────────────────────────────────────────────────────────

  程式位置四：tests/ics-export.test.js
  說明：ICS 純函式與下載行為測試。
  異動：涵蓋必要標頭、本地時間、重複單次、跨日、特殊字元跳脫、安全檔名、
        iOS UA 判斷、捷徑 payload 日期與成員、URL scheme/名稱/JSON 編碼、iOS 原生
        導向，以及非 iOS Blob MIME、anchor click 與 Object URL 回收。

  ─────────────────────────────────────────────────────────────────────────────

  程式位置五：index.html、css/style.css
  說明：iPhone 首次設定教學。
  異動：新增設定入口與 Modal，說明建立「新增家庭行程」捷徑、解析字典及對應
        title/startAt/endAt/notes 到「加入新行程」動作。

--------------------------------------------------------------------------------

【未修改項目】
  Firestore 行程資料模型
  說明：匯出資料由既有 event 與 occurrenceDateKey 即時計算，不需新增欄位或遷移資料。

  重複行程儲存規則
  說明：ICS 不輸出 RRULE，刻意只產生當下點選的單一 VEVENT，符合單次匯出需求。

--------------------------------------------------------------------------------

【測試建議】
  1. 一般行程從當日列表下載 .ics，確認標題、時間與成員正確。
  2. 從詳細 Modal 下載相同行程，確認內容一致。
  3. 點選重複行程第二次 occurrence，確認 ICS 日期為當次日期且沒有 RRULE。
  4. 使用含逗號、分號、反斜線與換行的標題，確認匯入後文字完整。
  5. 依首次設定 Modal 建立「新增家庭行程」捷徑，再從 iPhone Safari 點擊按鈕，
     確認捷徑立即執行並新增正確行程。
  6. 在窄螢幕確認三個操作按鈕可換行且不超出 Modal。
