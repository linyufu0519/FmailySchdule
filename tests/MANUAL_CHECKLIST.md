# 手動測試檢查清單（旺咪家行事曆）

自動化測試（`node --test tests/`）只涵蓋純函式邏輯（假日查詢、重複規則展開、衝突偵測、
Firebase 設定判斷、家庭 key 驗證與 familyId 設定）。以下項目需要在瀏覽器中實際操作驗證。

## 基本開啟（未設定 Firebase）

- [ ] 未建立 `js/firebase-config.js` 時，直接開啟 `index.html`（建議透過
      `python -m http.server` 啟動本機伺服器）不會出現任何錯誤或空白頁面
- [ ] 帳號列顯示「離線模式，尚未設定雲端同步」
- [ ] 畫面上不會出現任何登入表單/按鈕（Email、密碼欄位、登入/註冊/登出按鈕皆已移除）
- [ ] 點擊「新增行程」／「新增成員」會提示「尚未設定 Firebase，請參考 FIREBASE_SETUP.md」

## 月曆瀏覽

- [ ] 首頁顯示當月完整月曆（週日在最左、週六在最右）
- [ ] 「上一月」「下一月」按鈕可正確切換並更新標題年月
- [ ] 今天日期有醒目樣式
- [ ] 國定假日日期下方顯示假日名稱小字（例如 2026-01-01 顯示「元旦」）

## 家庭成員管理（需先設定 Firebase 並以合法家庭連結進入）

- [ ] 新增成員：姓名、簡稱（限 1 字元，超過 1 字元會提示錯誤）、顏色皆可正確儲存
- [ ] 成員列表顯示姓名、簡稱、簡稱顏色預覽
- [ ] 編輯成員可修改上述欄位並即時反映在列表與月曆上
- [ ] 刪除成員需二次確認

## 行程新增／編輯／刪除

- [ ] 點擊某日日期會開啟當日行程列表 Modal（新增行程後立即可在此看到剛新增的項目，無需重整）
- [ ] 行程依開始時間排序
- [ ] 內容過長時顯示「...詳細」，點擊後可看到完整內容（含成員、時間）
- [ ] 新增行程可複選相關成員（checkbox 僅顯示簡稱與顏色，不顯示全名）
- [ ] 選擇「開始時間」後，若尚未手動改過「結束時間」，會自動帶入「開始時間 + 1 小時」；
      手動修改結束時間後，改開始時間不會再覆蓋
- [ ] 開始時間需早於結束時間，否則提示錯誤
- [ ] 設定「每週」重複後，月曆上會固定展開「本次 + 未來 4 週」共 5 次；設定「每月」會固定
      展開「本次 + 未來 4 個月」共 5 次，皆不會無限展開
- [ ] 刪除重複行程時可選擇「刪除本次」（其餘次數仍存在）或「刪除全部」（全部消失）
- [ ] 儲存時若同一成員在相同時段已有其他行程，會顯示衝突警示文字（但仍可成功儲存）
- [ ] 刪除單筆行程（非重複）需二次確認

## 加入手機行事曆（需已設定 Firebase Storage）

- [ ] 點擊後按鈕立即顯示「正在準備…」並停用，不新開分頁
- [ ] 上傳完成後**目前分頁**導向 `https://firebasestorage.googleapis.com/...` 的 `.ics` 下載網址
- [ ] iPhone Safari 可在該分頁開啟行事曆匯入介面；標題、時間與參與成員正確
- [ ] 完成或取消匯入後，可用瀏覽器返回鍵回到家庭行事曆頁面
- [ ] 重複行程只匯出目前點選的 occurrence 日期，不含整個系列
- [ ] 跨日行程的結束日期正確
- [ ] 模擬上傳失敗時停留原頁，顯示「行事曆檔案產生失敗，請稍後再試」，按鈕恢復可點擊

## LINE 內建瀏覽器提示

- [ ] 用 LINE 開啟含 `?key=` 的完整連結，在 LINE 內建瀏覽器點「加入手機行事曆」
- [ ] 確認不會呼叫 Storage 上傳、不會產生檔案、不會有任何導向
- [ ] 顯示「請使用 Safari 加入行事曆」Modal，內容含操作步驟與安全提醒
- [ ] 「複製目前網址」按鈕可成功複製含 `?key=` 的完整目前網址（可貼到備忘錄確認）
- [ ] 若裝置 clipboard API 不可用，改為選取文字框內容並顯示提示訊息
- [ ] 依提示用 LINE 右上角選單「使用預設瀏覽器開啟」，在 Safari 重新點擊可正常匯出
- [ ] Safari／Chrome 等非 LINE 瀏覽器不受影響，維持原本上傳與同頁導向流程

## 月曆顯示細節

- [ ] 有行程的日期，日期數字放大並變色
- [ ] 日期上方顯示有行程的家庭成員簡稱，並以各自顏色顯示
- [ ] 同一天成員數量過多時（超過 4 位）以「+N」省略顯示

## 搜尋

- [ ] 輸入行程內容關鍵字，可搜尋到符合的行程
- [ ] 輸入家庭成員姓名，可搜尋到該成員相關的行程
- [ ] 點擊搜尋結果會跳轉到該行程所在月份並開啟當日行程 Modal

## 深色模式

- [ ] 右上角切換按鈕可切換淺色/深色主題
- [ ] 重新整理頁面後，深色模式偏好被記住（`localStorage`）
- [ ] 深色模式套用在月曆、Modal、表單、按鈕等所有元件

## 家庭連結匿名登入（需已設定 Firebase 並啟用 Anonymous）

- [ ] 未帶 `?key=`：顯示「唯讀模式（連結缺少或無效）」，不登入、不讀取 Firestore
- [ ] key 過短或含 `/`、空白、中文字：同樣維持唯讀，不出現登入錯誤
- [ ] 合法 key（至少 32 碼且只含英數、`_`、`-`）：匿名登入成功並顯示「已連線（可編輯）」
- [ ] 合法 key 登入後可新增成員與行程，重新整理相同完整網址後仍可查看
- [ ] 使用另一組合法 key 時，會進入獨立的空白家庭資料路徑
- [ ] 畫面上不會出現 Email、密碼、登入、註冊或登出 UI
- [ ] 唯讀狀態下嘗試新增/編輯資料，會提示「請使用有效的家庭專屬連結」
